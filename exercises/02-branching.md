# Exercise 2: Branching

This is Exercise 2 of the hands-on Git workshop. It focuses on branch work:

- `git branch` to create and list branches
- `git checkout -b` / `git switch -c` to start working on a new branch
- Merging branches with `git merge`
- visualize commit graphs with `git log --graph`

Tip for the demo: create the `student-exercises` branch from `main`, make your changes there, and merge back only when your commits look clean.
